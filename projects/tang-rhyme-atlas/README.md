# 千字同韵：数据与分析约定

这是“唐代韵部 × 官话、晋、吴、徽、赣、湘、闽、粤、客家 × 韩国、越南汉字音”的交互研究原型。客家话作为独立系统纳入；当前 1,000 字核心集采用客语辞典四县腔。

当前核心比较集包含 1,000 个常用字，均同时具有 Unihan `kTang`、`kMandarin`、`kCantonese`、`kKorean`、`kVietnamese` 与客语辞典四县腔读音。字序采用 [Jun Da 现代汉字频率序列的公开整理版](https://github.com/alyssabedard/zhongwen)，繁体字形优先；矩阵始终显示每一语言对的实际有效样本数。

四县客家话不再通过通用正则表达式猜测韵母。生成脚本以辞典的 PFS 字段为分类基础，依台湾客家语拼音方案的声母表作最长匹配，再去除声母与声调。PFS 本身明确区分阳声韵尾 `m/n/ng` 与入声韵尾 `p/t/k`；每条记录同时保留教育部“音读（符号）”字段。

运行 `python3 build_dataset.py` 可以从仓库内的 `Unihan.zip`、`frequency-junda.txt` 和 `hakka_sixian_source.csv` 重新生成 `data-1000.js`。

## 建议的数据流程

1. 字表：以现代常用字频率为基础，对 16 摄、四声与入声字设置最低配额。
2. 中古音：保存《广韵》小韵字段，并把拟音体系及版本写入 `source`，不可只留一列字符串。
3. 方言点：官话、晋、吴、徽、赣、湘、闽、粤、客家各选一个明确地点作为第一阶段代表点；大区名和地点名分栏。
4. 多音字：一字多行，每条读音设置 `reading_type`（文/白/常用/历史层次）与权重。
5. 转写：原始字典拼写与统一 IPA 分栏保存；所有比较都基于特征而不是拉丁字母。
6. 质检：每条记录保留来源、页码或条目链接、录入者、复核者与状态。

## 核心问题：同韵保持率

对每个语言系统，先根据明确的韵母字段把同一批汉字划分为若干韵部。当前中古侧采用与读音逐字对齐的 Unihan `kTang` 韵母；现代侧去除介音后按主元音与韵尾组成的韵基归部，介音另列。对于源系统 A 的每一个韵，以目标系统 B 中字数最多的韵部作为主要对应；落入主要对应的字记为保持，其余字记为分化。

“小学堂”查询页中的《广韵》栏暂不直接用于计分：多音字页面默认展示的首条历史音义未必与方言栏所列的常用读音对应（例如“出”会显示至韵），会制造假的韵部分裂。只有完成音义级对齐后，才可把该字段作为正式《广韵》标签接入。

`R(A→B) = 各源韵主要对应中的字数之和 / 共同有效字数`

这是单向指标，只计算 `R(A→B)`。B 将多个 A 韵合并不会降低分数；A 中的一个韵在 B 中发生分化时，只有人数最多的目标韵计为主要对应。单字源韵也按一个有效字计入，但应另行报告其数量，因为它不能提供韵内一致性的证据。

中古汉语与现代系统采用同一分类比较框架。当前 1,000 字核心集使用 Unihan `kTang` 拟音去除声母、声调后的标准化韵母；这是一项可运行的操作性分类，不冒充完整《广韵》韵目。未来接入小韵、摄、等、呼等字段时，应与 `kTang` 分类并列保留。

## 其余方言数据

晋语、吴语、徽语、赣语、湘语、闽语采用中央研究院资讯科学研究所与台湾大学中国文学系共同建设的“小学堂”分库。查询结果直接包含方言点、声母、韵母、调值、调类，以及《广韵》摄、韵目、声调、等第、开合等字段。预定代表点为太原、苏州、绩溪、南昌、长沙、厦门；导入时保留原始字段及查询日期。

## 分析建议

当前关系矩阵主分数为有方向的同韵保持率。细韵母 partition 的 ARI 作为补充，用于描述两套分类整体的合流与分化。

- 韵尾保留率：中古韵尾特征在现代系统中的规则对应率。
- 特征距离：介音、主元音、韵尾、声调分别计算，再报告不同权重下的稳健性。
- 系统关系：以韵类 partition 的 ARI/RI 构成矩阵，再做层次聚类与 bootstrap；不要把分类相似直接解释为谱系。
- 分韵部视图：至少按韵摄、韵、声调和等呼筛选，并同时报告样本量。
- 缺失与多音：不得把缺失读音当作零，也不得静默选取对结论最有利的读音。
